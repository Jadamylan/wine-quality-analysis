the question

Can chemistry help explain wine quality?

The original project asked which measurable wine characteristics showed the strongest relationship with quality. We narrowed a combined red-and-white dataset to white wine and used multiple linear regression, correlation analysis, model selection, transformations, diagnostics and regression trees.

Portfolio note: This version currently visualizes the reported results from the 2022 project. A full row-level rerun can be wired in as soon as the original CSV is added to the repository.

Measures included acidity, sugar, chlorides, sulfur dioxide, density, pH, sulphates and alcohol. Quality was a discrete expert score, making the project suitable for both regression-style and classification-style thinking.

what stood out

Alcohol up. Volatile acidity down.

Density

The fun takeaway from 2022: if I was choosing only from the variables in this dataset, higher alcohol and lower volatile acidity were two of the clearest signals associated with higher quality.

the model glow-up

Four versions, one modest ceiling

The original analysis progressively simplified and transformed the model. Adjusted R² improved only slightly, which is an important result itself: chemistry alone leaves a lot of human taste unexplained.

How to read the original coefficients

log(volatile acidity) carried a negative coefficient: holding the other variables constant, higher logged volatile acidity was associated with lower quality.

Alcohol carried a positive coefficient: holding the other variables constant, higher alcohol was associated with higher quality.

What the R² is telling us

Even the best reported version explained only about 29% of the variation in quality. That is not a failure; it is evidence that sensory ratings contain information the lab measurements do not capture — including human preference, context and possibly omitted production variables.

2026 extension

If I rebuilt this analysis today…

01 · Respect the outcome

Quality is ordered and discrete. Compare ordinary regression with ordinal logistic regression instead of treating the score as purely continuous.

ordinal regressionmodel fit

02 · Predict out of sample

Add a train/test split and repeated cross-validation. Report MAE/RMSE and compare models based on how well they generalize.

cross-validationRMSE

03 · Test nonlinearity

Compare the interpretable linear model to random forest, gradient boosting and generalized additive models.

random forestGAM

04 · Bring red wine back

Model wine type explicitly and test whether alcohol, acidity or sulfur behave differently for red vs. white wines.

interactionssegmentation

05 · Explain predictions

Add permutation importance or SHAP-style explanations so a visitor can see why a model scores a particular wine higher or lower.

interpretabilityfeature importance

06 · Go beyond chemistry

If new data were available, add producer, vintage, region, fermentation/aging variables and sensory-panel information — the missing 70% is the interesting part.
